# Spec HU-018 — Visualización Consolidada de CGs (Gerente)
**Sprint:** 3 · **Épica:** EP-06 · **Pts:** 3 · **Estado:** Implementado

## Contexto
Backlog `03_BACKLOG.md` L359-370: *"Como GER quiero ver todos los Objetivos CG de todas las áreas en una vista consolidada para revisar el panorama completo de compromisos estratégicos del ciclo"*.

**Decisión de Arquitectura (D-A):** La funcionalidad de "exportar a Excel" solicitada en los CA se delega enteramente a la capa de frontend (HU-045+) que consumirá este mismo endpoint y construirá el archivo. Esta API debe mantenerse estrictamente REST retornando JSON puro bajo `ApiResponse<T>`, cumpliendo `ARCH-07`.

## Endpoints

| Método | Ruta | Auth | Descripción |
|---|---|---|---|
| GET | `/api/v1/objetivos-cg/consolidado` | Bearer (Gerente) | Obtiene la lista consolidada de CGs del ciclo activo con filtros dinámicos. |

> **Justificación de Ruta (D-B):** Se opta por una ruta standalone `/consolidado` y no bajo `/ciclos/{cicloId}` para mantener coherencia con `HU-016` (Dashboard Gerente), resolviendo el ciclo activo internamente en el servidor en base al Tenant, lo que elimina un parámetro extra del cliente y asegura que el Gerente siempre vea la foto actual por defecto.

## Lógica BLL (paso a paso)

Servicio: `PE-GOL.BLL/Services/ObjetivoCgService.cs`. Se extiende aditivamente con:
`Task<ApiResponse<IEnumerable<ObjetivoCgConsolidadoResponse>>> ListarConsolidadoGerenteAsync(ObjetivoCgFilterRequest filtros, CancellationToken ct)`

1. **Guardas de Acceso:** 
   - Validar que `_tenantContext.Rol == "Gerente"`. Lanza `AccesoDenegadoException` si no.
2. **Contexto Tenant:** Obtener `TenantId` del JWT. Lanza `NotFoundException` si es null.
3. **Ciclo Activo:** `_cicloRepository.ObtenerCicloActivoAsync(tenantId)`. Si null, lanza `NotFoundException`.
4. **Verificación RLS & SEC-07:**
   - Según `06_MODELO_DATOS.md` L513, `objetivo_cg_policy` permite a `auth.user_rol() IN ('Gerente')` ver todos los registros del tenant. **SEC-07 NO APLICA** ya que el Gerente requiere visibilidad global.
5. **Consulta DAL:** Llamar a `IObjetivoCgRepository.ListarConsolidadoGerenteAsync(tenantId, ciclo.Id, filtros, ct)`.
6. **Retorno:** Envolver la lista resultante en `ApiResponse<IEnumerable<ObjetivoCgConsolidadoResponse>>` y retornar.
7. **Auditoría:** No se invoca `InsertLogAsync` (es operación puramente de lectura).

## Queries DAL

Se agregará en `ObjetivoCgRepository.cs`:

```sql
SELECT 
    o.id, 
    o.area_id, a.nombre AS area_nombre, a.codigo AS area_codigo,
    o.pilar_id, p.nombre AS pilar_nombre, 
    o.codigo, 
    o.descripcion, 
    o.trimestre_objetivo::text, 
    o.progreso, 
    o.semaforo::text, 
    o.created_at, 
    o.updated_at
FROM objetivo_cg o
INNER JOIN area a ON o.area_id = a.id
INNER JOIN pilar p ON o.pilar_id = p.id
WHERE o.tenant_id = @TenantId 
  AND o.ciclo_id = @CicloId
  /* Uso de Dapper SqlBuilder para concatenar condiciones if not null */
  -- AND o.area_id = @AreaId
  -- AND o.pilar_id = @PilarId
  -- AND o.trimestre_objetivo = @Trimestre::trimestre
  -- AND o.semaforo = @Semaforo::semaforo_color
ORDER BY a.nombre ASC, o.orden ASC, o.created_at ASC;
```
