# ADR-004 — Paquete `System.IdentityModel.Tokens.Jwt` en `PE-GOL.Utility` para emisión de tokens JWT

**Fecha:** 2026-09-13 · **Estado:** Aceptado
**Autor:** Jorge (Dicegsa) / @Arquitecto

## Contexto

`04_ARQUITECTURA.md` § 2 declara el "JWT helper" en `PE-GOL.Utility` (capa transversal), pero no existe en código. HU-004 (Autenticación) necesita generar access tokens (SEC-01: 60 min) y refresh tokens (7 días). El paquete `System.IdentityModel.Tokens.Jwt` YA está referenciado en `PE-GOL.API/Program.cs` L66-85 para validación de tokens; el ADR formaliza su uso también para **emisión** en `PE-GOL.Utility`.

Regla del proyecto: nueva librería fuera del stack declarado en AGENTS.md → ADR obligatorio (decisión de Jorge, Flag #4 del spec HU-004).

## Opciones consideradas

1. **`System.IdentityModel.Tokens.Jwt` en `PE-GOL.Utility` (recomendada)** — mismo paquete que ya valida en la API, sin dependencia nueva, ecosistema Microsoft mantenido.
2. **`JWT.NET` / `jose-jwt`** — alternativa ligera pero librería externa adicional sin necesidad.
3. **Emisión manual de JWT sin librería** — firmar HMAC a mano: inseguro, propenso a errores de codificación Base64Url/claims. **Rechazada.**

## Decisión

Añadir `System.IdentityModel.Tokens.Jwt` (+ `Microsoft.IdentityModel.Tokens` si es necesario como dependencia transitiva) al proyecto `PE-GOL.Utility`. `JwtTokenHelper` (Utility/Security) genera access tokens con claims `user_id`, `tenant_id` (omitido si null), `rol`, `area_id` (omitido si null) y expiración configurable vía `JwtOptions` (enlazado de `Jwt:AccessTokenMinutes=60`, `Jwt:RefreshTokenDays=7` de appsettings). El refresh token NO es JWT: 32 bytes aleatorios → Base64Url, persistido como hash SHA-256 (D2 del spec HU-004).

## Consecuencias

**Positivas:**
- Mismo paquete para validación y emisión, sin dependencias nuevas.
- Patrón documentado y reutilizable por futuras HUs.
- `JwtOptions` centraliza la configuración de expiración (SEC-01) en una sola fuente.

**Trade-offs aceptados:**
- `PE-GOL.Utility` pasa a depender de una librería de seguridad (aceptado: es su rol transversal).
- El ADR debe citarse en el spec HU-004 (referencias cruzadas y Criterios de Done).
